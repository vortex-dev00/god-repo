# 📊 Datasets & Benchmarks

> Training data, evaluation suites, and model leaderboards.

## Where to Find Datasets

- **Hugging Face Datasets** — 100k+ datasets for every ML task — https://huggingface.co/datasets
- **Kaggle Datasets** — 200k+ community datasets — https://www.kaggle.com/datasets
- **Papers With Code Datasets** — Datasets linked to papers — https://paperswithcode.com/datasets
- **Common Crawl** — Petabytes of web crawl data — https://commoncrawl.org/
- **The Pile (EleutherAI)** — 800GB diverse text dataset — https://pile.eleuther.ai/
- **RedPajama** — Open-source LLM training data — https://github.com/togethercomputer/RedPajama-Data
- **LAION** — Open image-text datasets — https://laion.ai/
- **FineWeb (Hugging Face)** — 15T token web dataset — https://huggingface.co/datasets/HuggingFaceFW/fineweb
