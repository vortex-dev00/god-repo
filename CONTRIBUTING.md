# 🤝 Contributing to The God Repo

Thanks for helping make this the ultimate AI resource!

## How to Contribute

### Adding a new tool/resource

1. Fork this repo
2. Find the right folder for your entry
3. Add it to the `README.md` in that folder
4. Use this format:

```
- **Tool Name** — One-line description — https://link.com/
```

If it's a GitHub repo, add stars: `⭐ 45k`

### Guidelines

- ✅ One line per entry (name, description, link)
- ✅ Put entries in the correct category folder
- ✅ Mark unverified entries with `[?]`
- ✅ Include pricing info where relevant (🆓 = free, 💰 = paid)
- ✅ Keep descriptions short (one line)
- ❌ No affiliate links
- ❌ No spam / self-promotion without genuine value
- ❌ No duplicates (search first!)

### Fixing something

- Broken link? Open a PR or issue
- Wrong description? Open a PR
- Tool shut down? Open a PR to remove it

### Suggesting a new category

Open an issue with the title: `[Category] Your suggested category name`

## Quality Standards

- Every entry must be a real, working tool/resource
- Descriptions should tell you what it IS, not marketing speak
- Links must work
- Star counts should be approximate and recent

## Questions?

Open an issue! We're friendly.
