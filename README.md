## 🔍 How to Use This Repo

1. **Browse by folder** — click into the section that matches your need
2. **Search** — use GitHub's search (`/` key) or `Ctrl+F` to find anything
3. **Every entry format:** `**Name** — description — [Link](URL)`

**Legend:** ⭐ = GitHub stars | 💰 = paid | 🆓 = free tier | 🔓 = open source | [?] = unverified
