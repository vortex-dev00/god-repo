### Who's Winning (Developer Tools)
| Tool | Position | Key Metric |
|------|----------|-----------|
| **GitHub Copilot** | User count leader | 4.7M paid subs |
| **Cursor** | Revenue leader | $2B ARR, 1M+ paying |
| **Claude Code** | Satisfaction king | 46% most-loved (JetBrains), 91% CSAT |
| **Aider** | Terminal veteran | 44K stars, 6.8M installs |

**The standard 2026 dev setup:** Cursor for editing + Claude Code for complex tasks + Copilot for inline completions.

### What Exploded in 2026
- **Claude Code**: 3% → 18% work adoption in 12 months
- **MCP**: 9,400 servers, 150M+ downloads, adopted by ALL major platforms
- **Context Engineering**: CLAUDE.md / .cursorrules / AGENTS.md = new team standards
- **Vibe coding**: Meme → MIT's "10 Breakthrough Technologies of 2026"

### What Died/Declined
- **Windsurf** → Acquired by Cognition ($250M), rebranded Devin Desktop
- **Copilot flat-rate** → Usage-based billing caused 10-50x bills, massive backlash
- **"One tool wins"** assumption is dead — everyone stacks multiple AI tools
