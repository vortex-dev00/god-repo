## 🏁 Quick-Start Decision Guide

### "I just want to chat with AI for free"
→ **ChatGPT** (broadest features), **Claude** (best writing), **DeepSeek** (unlimited)

### "I want to run AI on my own computer"
→ Install **Ollama** → Download **Qwen 3 8B** or **Llama 3.1 8B** → Chat locally forever

### "I want to generate images for free"
→ **Copilot Designer** (easiest) or install **ComfyUI** + **Flux Schnell** (unlimited local)

### "I want to learn AI/ML from zero"
→ **Elements of AI** → **fast.ai** → **Stanford CS229** on YouTube

### "I'm a developer who needs free AI tools"
→ **Codeium** (unlimited completions) + **Google AI Studio** (1M tokens/day) + **Colab** (free GPU)

### "I need to transcribe audio/video"
→ **Whisper** locally (unlimited) or **Otter.ai** free tier (300 min/month)

## 📝 Notes

- **"Open-weight" vs "Open-source"**: Most models (Llama, Gemma) are open-weight (downloadable) but have license restrictions. True open-source (Apache 2.0 / MIT) includes Qwen, Mistral Small, DeepSeek.
- **Free tiers change constantly**: Always verify current limits on the provider's website.
- **Hardware for local models**: 8B models need ~6GB VRAM (or 8GB RAM for CPU). 70B models need ~48GB VRAM or heavy quantization.
- **Quantization formats**: GGUF (llama.cpp/Ollama), GPTQ, AWQ, EXL2 — all reduce model size for consumer hardware.
