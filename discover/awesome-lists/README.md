**Foundational:**
- "Attention Is All You Need" (2017) — Transformer architecture — https://arxiv.org/abs/1706.03762
- "BERT" (2018) — Bidirectional pre-training — https://arxiv.org/abs/1810.04805
- "GPT-3: Language Models are Few-Shot Learners" (2020) — In-context learning — https://arxiv.org/abs/2005.14165
- "Chinchilla: Training Compute-Optimal LLMs" (2022) — Scaling laws — https://arxiv.org/abs/2203.15556

**Reasoning & Agents:**
- "Chain-of-Thought Prompting" (2022) — Step-by-step reasoning — https://arxiv.org/abs/2201.11903
- "ReAct: Reasoning and Acting" (2022) — Tool-using agent foundation — https://arxiv.org/abs/2210.03629
- "Tree of Thoughts" (2023) — Branching problem-solving — https://arxiv.org/abs/2305.10601
- "Generative Agents" (2023) — LLM agents with memory — https://arxiv.org/abs/2304.03442

**Alignment:**
- "InstructGPT / RLHF" (2022) — Foundation of ChatGPT — https://arxiv.org/abs/2203.02155
- "Constitutional AI" (2022) — Self-improvement principles — https://arxiv.org/abs/2212.08073
- "DPO: Direct Preference Optimization" (2023) — Simplified RLHF — https://arxiv.org/abs/2305.18290

**RAG & Tools:**
- "Retrieval-Augmented Generation" (2020) — Knowledge grounding — https://arxiv.org/abs/2005.11401
