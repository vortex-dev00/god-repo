## 6. BENCHMARKS & LEADERBOARDS

The standardized tests for AI models — what they measure and where to find results.

### 🏅 Major Leaderboards

| # | Name | Description | URL |
|---|------|-------------|-----|
| 1 | **LMSYS Chatbot Arena** | Human preference evaluation — blind pairwise battles, Elo ratings, 6M+ votes. As of 2026: Anthropic, xAI, Google, OpenAI all occupy top tier (~1,400-1,500 Elo) | https://openlm.ai/chatbot-arena |
| 2 | **Open LLM Leaderboard** | Hugging Face's open-source model rankings — standardized eval suite, community-submitted models | https://huggingface.co/spaces/open-llm-leaderboard/open_llm_leaderboard |
| 3 | **Papers With Code** | State-of-the-art tracking — every ML task has a leaderboard with linked papers and code. 5,000+ benchmarks | https://paperswithcode.com |
| 4 | **Artificial Analysis Intelligence Index (AAII)** | Aggregates 10 challenging evaluations into single intelligence score — v3 methodology | https://artificialanalysis.ai/leaderboards/models |
| 5 | **Stanford AI Index Report** | Annual comprehensive AI progress report — covers technical performance, economic impact, policy. Authoritative industry reference | https://hai.stanford.edu/ai-index |
| 6 | **ARC Prize** | Tests few-shot generalization on novel tasks — measures a core aspect of intelligence. Annual competition with $1M+ prizes | https://arcprize.org |

### 📐 Key Benchmarks Explained

| Benchmark | What It Measures | Details | Where to Find Results |
|-----------|-----------------|---------|----------------------|
| **MMLU** (Massive Multitask Language Understanding) | Broad knowledge across 57 subjects — humanities, STEM, social sciences, professional domains. Multiple-choice format. The most-cited general LLM benchmark | 14,042 questions across 57 tasks | Papers With Code, Open LLM Leaderboard |
| **HumanEval** | Code generation — 164 hand-crafted Python problems with unit tests. Measures functional correctness with pass@k metric. Created by OpenAI for Codex evaluation | 164 problems, Python only | Papers With Code, model release cards |
| **GSM8K** | Grade-school math reasoning — 8,500 multi-step arithmetic word problems. Tests chain-of-thought reasoning and multi-step computation | 8,500 problems (7,473 train / 1,319 test) | Papers With Code, Open LLM Leaderboard |
| **GPQA** (Graduate-Level Google-Proof QA) | Expert-level questions that can't be Googled — written by domain PhDs. Tests deep reasoning beyond memorization | ~450 questions, verified by domain experts | Chatbot Arena, AI Index Report |
| **MMMU** (Massive Multi-discipline Multimodal Understanding) | Multimodal reasoning — requires understanding images, charts, diagrams alongside text. College-level subjects | 11,500 questions with images | Papers With Code |
| **SWE-bench** | Real-world software engineering — resolve actual GitHub issues from popular repos. Tests end-to-end coding ability | Real PRs from 12 popular Python repos | Papers With Code, SWE-bench.com |
| **HellaSwag** | Commonsense reasoning — sentence completion requiring real-world knowledge | 10,000 questions | Open LLM Leaderboard |
| **TruthfulQA** | Truthfulness — tests whether models generate false claims on topics where humans often have misconceptions | 817 questions | Open LLM Leaderboard |
| **ARC (AI2 Reasoning Challenge)** | Science reasoning — grade-school level science questions requiring multi-step reasoning | 7,787 questions (easy + challenge) | Open LLM Leaderboard |
| **Winogrande** | Commonsense pronoun resolution — "The trophy doesn't fit in the suitcase because it is too [big/small]" | 44,000 problems | Open LLM Leaderboard |
| **MATH** | Competition mathematics — AMC/AIME level problems requiring multi-step mathematical reasoning | 12,500 problems across 7 subjects | Papers With Code |
| **MT-Bench** | Multi-turn conversation quality — judges model ability to maintain coherent, helpful multi-turn dialogue | 80 multi-turn questions, GPT-4 judge | LMSYS |
| **AlpacaEval** | Instruction following — measures how well models follow natural language instructions compared to reference | Win rate vs. reference model | Papers With Code |
